# 家庭电视 UI 规范

设计基线为 0.4.9 首页。五个顶部入口的统一实现属于 0.4.10 开发版本；设备发布需要独立验收。

## 视觉语言

- 以实际内容背景、深色半透明玻璃、白字与白色细焦点框为主体。保留首页四卡、独立背景、圆角与 `GlassView`，不引入亮色实心选中条或系统默认对话框。
- 主字色 `#FFFFFF`，次级文字 `#BBFFFFFF`，边缘 `#28FFFFFF`，焦点边缘 `#CCFFFFFF`。菜单背景采用 `#EB15212D` 到 `#EB0B141E` 的深色玻璃渐变，保证画面较亮时的可读性。
- 字体复用首页 `UiFont` 和现有 medium/body 资源。面板标题 22sp、选项 17sp、说明与操作提示 13sp。标题、说明、内容左对齐；不增设装饰性标签。
- 菜单面板圆角 20dp、内边距 20dp；列表行 58dp（包含焦点光晕空间）、图标 22dp、焦点圆角 16dp。焦点直接复用首页 `GlassView`，白字不反转成黑字；禁用系统默认焦点块，避免圆角外出现矩形底色。

## 五个顶部入口

输入源、最近打开、网络、应用库、设置共用 `HomeMenu`，同一位置、尺寸、标题区、内容区和底部提示。标准面板 800×360dp，居中显示并按可用屏幕尺寸收缩。窄列表不再另开小下拉框；应用库保留适合遥控器的横向 16:9 应用卡。

```
┌────────────────────────────────────┐
│ 标题                               │
│ 说明 / 当前状态                    │
│                                    │
│ 列表选项，或横向应用卡片           │
│                                    │
│ 方向键选择 · 确定打开 · 返回关闭    │
└────────────────────────────────────┘
```

- 首页与菜单都保持全屏，不因弹窗切换导航条而改变可用高度或裁切卡片名称。打开统一淡入 180ms；关闭返回原入口；减少动态效果时复用 `Motion.REDUCED_MS`，关闭动画设置时立即显示。
- 弹出面板时保留当前首页背景并统一模糊；应用库内移动焦点不替换首页背景。面板内容始终清晰。
- 列表上下移动，到首尾停止；左右不离开列表。长列表在同一面板内滚动；返回关闭；HOME 恢复首页。初始聚焦首个可操作项，不能因开启菜单的确认键抬起而误触首项。
- 最近打开明确标注为本地入口记录，极光观看历史单独提供；不冒充播放进度。
- 网络先显示统一菜单，再提供 Wi-Fi 设置和已配置的网络应用；设置先显示统一菜单，再提供系统设置、桌面设置等实际操作。系统或第三方应用打开后的内部界面由各应用负责。
- 应用库保留启动、添加/移除首页、长按管理能力。内部管理菜单仍用相同字体、玻璃焦点和列表行组件。

## 验收

检查五菜单同一外框与标题位置，真实模拟器像素、长列表末项可达、首尾焦点约束、返回原入口、HOME、输入源与历史路由、网络/系统设置跳转、应用库启动与管理；执行首页回归。测试替身只证明路由与 UI，不证明真实电视信号、网络或播放。
