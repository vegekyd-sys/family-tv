# 家庭电视 UI 规范

0.4.11 将共用的 Liquid Glass 控件接入五个菜单，按内容决定尺寸与布局。真实设备发布仍需要对应版本授权与单独验证。

## 材质与字体

- 背景透色与局部模糊、边缘折射、方向性细反光共同表达玻璃。静止、聚焦和按压保持同一深色透光底 `#7010161F`，无白色或灰白色面填充。
- 正文 `#FFFFFF`，次级文字 `#BFFFFFFF`，辅助提示 `#A8FFFFFF`。没有固定品牌色光斑，也不使用粗白圈或气泡外框。
- 字体沿用 `UiFont`；标题 23sp、文字入口 17sp、图标按钮/内容名称 14sp、状态 11–12sp。
- `LiquidGlassAction` 共用焦点 2.5% 抬升、薄边反射与独立按压回弹；确认键抬起才触发，支持长按，减少动态效果或关闭动画时立即变化。
- `LiquidGlassBackdrop` 采样独立首页内容层，后台模糊、共享缓存；弹层不采到自己。菜单打开后补采样以覆盖原首页背景过渡；滚动停止后重采样控件位置。

## 五个菜单的排版

全部位于顶部控件下方，右边对齐首页留白。没有覆盖整个控件组的大外框；尺寸与方向导航跟随实际内容。

| 菜单 | 排版 | 尺寸原则 |
| --- | --- | --- |
| 输入源 | 设备图标与名称横排，每行最多四项 | 单项约 158dp 容器，随数量增加；多项换行并允许滚动 |
| 最近打开 | 标题旁独立的极光观看历史入口，下方为实际内容卡 | 最多四卡一行；空状态只保留简短说明，不撑出空白大面板 |
| 网络 | 当前连接状态，下方 Wi-Fi 与配置的网络应用并排 | 一或两个操作，约 158–302dp 宽；不是连接开关 |
| 设置 | 两个文字导航入口，下方并排编辑操作 | 294dp 宽；内容卡片、程序坞等可选项按配置增加，不留空槽 |
| 应用库 | 四列应用网格，最多两行可视区域，继续下移滚动 | 672dp 宽；只有应用浏览需要较大空间，保留原应用图标与名称 |

标题与说明左对齐。内容卡与应用图标使用实际资源，不重新生成品牌图案。首页仅轻微压暗，底部卡片保持清晰；弹层内有唯一可操作焦点。

## 交互与兼容

- `HomeMenu` 共用生命周期，不规定统一尺寸和排版。返回恢复原入口；HOME 关闭菜单并回到 NBA 首屏；打开菜单的确认键抬起不能误触第一项。
- 方向键按实际空间移动，边界停止；长列表、换行输入源、应用网格滚动到目标后焦点仍可达。
- 最近打开仅为本地入口记录；真实观看进度由极光观看历史提供。
- 输入源保留 HDMI/CEC/厂商路由，网络保留系统 Wi-Fi 与配置应用入口，设置保留系统设置/桌面设置/编辑操作。
- 应用库保留打开、添加/移除首页、长按管理和返回焦点；长按不再额外触发短按。
- API 26 共同路径为 Bitmap/Canvas 缓存采样；目前没有连续视频背景跟踪或专用 AGSL 后端。目标电视性能仍需单独验收。

## 验收

检查五个菜单的不同布局与实际像素、焦点不增白、文字不裁切、四向边界、长列表滚动、短按/长按、返回/HOME，以及原首页回归。测试替身只证明入口与路由，不证明真实电视信号、网络和播放。
